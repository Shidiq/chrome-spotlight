Google Calendar

Which calendars the new tab shows

Connecting a work or school account
  1. Open console.cloud.google.com signed in as that account and create a project, or pick one you can use.
  2. Enable the Google Calendar API for it.
  3. Create an OAuth client of type Web application — a Chrome Extension client will refuse the redirect URI.
  4. Add the redirect URI above under Authorized redirect URIs.
  5. Copy the client ID into the box next to Add account below, then add the account.

Leave the client ID empty for a normal Google account. A work or school account is usually refused by the built-in client, and needs its own from a project it can reach — it is remembered per account and can be changed later without removing the account.

New calendars you create or subscribe to show up here on their own and follow their visibility in Google Calendar until you tick or untick them.
